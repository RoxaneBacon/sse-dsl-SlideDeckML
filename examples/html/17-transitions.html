Slide Transitions

This presentation demonstrates different slide transitions.

The global transition is set to "slide" in the metadata.

Fade Transition

This slide uses the fade transition.

Content smoothly fades in and out.

Convex Transition

This slide uses the convex transition.

Slides at a convex angle.

Concave Transition

This slide uses the concave transition.

Slides at a concave angle.

Zoom Transition

This slide uses the zoom transition.

The incoming slide grows from the center!

No Transition

This slide uses no transition.

It appears instantly.

Mixed Transitions (In)

This slide uses slide-in fade-out.

It slides in but fades out when leaving.

Mixed Transitions (Out)

This slide uses fade-in slide-out.

It fades in but slides out when leaving.

Creative Combinations

This slide uses fade-in zoom-out.

Fades in, then zooms out!

Back to Default

This slide returns to the default "slide" transition set in metadata.

No transition attribute specified = uses global setting.

Available Transitions

Basic: none, fade, slide, convex, concave, zoom

Mixed: slide-in fade-out, fade-in slide-out, etc.
