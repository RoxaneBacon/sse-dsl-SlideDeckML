Why SlideDeckML?

The Problem

Creating presentations is time-consuming and tedious

  • Writing HTML/CSS manually is complex
  • WYSIWYG tools lack version control
  • Markdown is limited in features

Our Solution

A Domain-Specific Language that combines simplicity with power!

What is SlideDeckML?

A high-level DSL built with Langium that compiles to Reveal.js presentations

Key Features:

  • Simple markdown-like syntax
  • Advanced code highlighting with sync fragments
  • LaTeX equation support
  • Rich media: images, videos, and YouTube
  • Custom CSS styling and positioning
  • Interactive chalkboard for annotations
  • Fragment animations and transitions
  • 5 professional templates ready to use

Feature 2: Code Highlighting

Our most powerful feature for technical presentations

Mode: line-by-line

def fibonacci(n):
    if n == 0 or n == 1:
        return n
    return fibonacci(n - 1) + fibonacci(n - 2)

result = fibonacci(10)
print(f"Fibonacci(10) = {result}")

Each line appears progressively - perfect for teaching!

How It Works

SlideDeckML Architecture

1. Write - Create `.sdml` files using our simple syntax

2. Parse - Langium processes your DSL code

3. Generate - Our compiler outputs Reveal.js HTML

4. Present - Open in any browser and present!

Technology Stack

Built with modern, proven technologies

Langium

TypeScript-based DSL framework

Reveal.js

HTML presentation library

VS Code

Syntax highlighting extension

Node.js

CLI compiler and dev server
