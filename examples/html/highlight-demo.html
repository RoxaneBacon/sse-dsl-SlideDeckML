Welcome

This presentation demonstrates the new abstract code highlighting features.

Line-by-Line Highlighting

Shows each line progressively:

function greet(name) {
    console.log('Hello ' + name);
    return true;
}

Block Highlighting

Highlights blocks separated by empty lines:

function first() {
    console.log('First function');
}

function second() {
    console.log('Second function');
}

function third() {
    console.log('Third function');
}

Function Highlighting

Detects and highlights functions individually:

function add(a, b) {
    return a + b;
}

function multiply(a, b) {
    return a * b;
}

function divide(a, b) {
    if (b === 0) return null;
    return a / b;
}

Class Highlighting

Highlights class definitions:

class Animal {
    constructor(name) {
        this.name = name;
    }
    
    speak() {
        console.log(this.name + ' makes a sound');
    }
}

class Dog extends Animal {
    speak() {
        console.log(this.name + ' barks');
    }
}

All at Once

Highlights everything immediately:

const x = 10;
const y = 20;
const sum = x + y;
console.log(sum);

No Highlighting

No progressive highlighting:

const x = 10;
const y = 20;
const sum = x + y;
console.log(sum);

Reveal.js Compatible

Still supports traditional reveal.js syntax:

const x = 10;
const y = 20;
const sum = x + y;
console.log(sum);

Mixed Syntax

Can combine highlight mode with start offset:

def calculate(x, y):
    result = x + y
    return result

def process(data):
    cleaned = data.strip()
    return cleaned.upper()
