Simplified syntax for grid layouts

⚠️ Important: columns vs nested columns

`columns: N` (grid) - Pour éléments simples (images, items)

  • Chaque élément enfant = une cellule de grille

`:::: / :::` (nested) - Pour grouper du contenu

  • Permet de mettre plusieurs éléments dans une colonne

❌ Grid NE MARCHE PAS pour du contenu groupé

Ceci est incorrect :

::: {columns: 2}
### Column 1
Content A

### Column 2
Content B
:::

Résultat : "### Column 1" dans cellule 1, "Content A" dans cellule 2, etc.

Les abstractions se combinent

Résumé

Grid (`columns: N`):

  • ✅ Images
  • ✅ Items simples
  • ❌ Contenu groupé

Nested (`:::: / :::`):

  • ✅ Contenu groupé
  • ✅ Multiple éléments par colonne
  • ✅ Largeurs personnalisées

Conseil pratique

Si vous hésitez, utilisez nested columns (`:::: / :::`) - c'est plus flexible !

Grid est surtout utile pour des galeries d'images.
