Part 9: Interactive Chalkboard

Chalkboard Feature

This presentation includes interactive chalkboard functionality!

  • Draw and annotate directly on slides
  • Toggle between presentation and drawing modes
  • Use keyboard shortcuts or buttons
  • Perfect for live presentations and teaching

How to Use Chalkboard

Keyboard Shortcuts:

  • Press C to toggle Chalkboard Mode (draw over slides)
  • Press B to toggle Notes Canvas (draw on black board)
  • Press DEL or BACKSPACE to clear drawings
  • Press D to download drawings as JSON

Mouse/Touch:

  • Click the chalkboard buttons at the bottom of slides
  • Draw with mouse or touch input

Chalkboard Modes

Chalkboard Mode (Press C):

  • Draw directly over slide content
  • Annotate diagrams and code
  • Highlight important points

Notes Canvas (Press B):

  • Opens a blank chalkboard for sketching
  • Great for explaining concepts from scratch
  • Like a traditional blackboard

Try It Now!

Press C to start drawing on this slide!

You can:

  • Circle this text
  • Draw arrows
  • Add your own notes
  • Underline key points

Press DEL to clear when done.
